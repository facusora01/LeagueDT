# LeagueDT - Project Overview and Vision

## Project Name
**LeagueDT** - League of Legends Director Técnico (Coach Assistant)

## Project Vision
Create a legal, non-bannable in-game overlay coaching assistant for League of Legends players that provides strategic insights and recommendations directly over the game window. The application runs completely locally on each user's machine, connecting directly to Riot Games APIs for real-time data and updates.

## Core Value Proposition
- **Legal and Compliant**: Uses only official Riot Games APIs, ensuring no ToS violations
- **In-Game Overlay**: Displays strategic information directly over the game window for seamless experience
- **Local-Only Architecture**: Runs entirely on user's machine with no cloud dependencies or server requirements
- **Real-Time Updates**: Automatically syncs with Riot APIs for patches, new champions, buffs, and nerfs
- **Data-Driven Decisions**: Leverages match data, gold analysis, and enemy composition for recommendations
- **Player Improvement**: Helps players understand optimal strategies rather than playing for them

## Target Users
- **Ranked Players**: Players looking to climb the ladder with strategic advantages
- **Learning Players**: Newer players wanting to understand optimal picks and item builds
- **Team Players**: Players who want to optimize their contribution to team composition
- **Analyst Types**: Players who enjoy data-driven decision making

## Key Differentiators
1. **Legal Compliance**: No memory reading, no injection, no automation - pure API usage
2. **In-Game Overlay**: Information displayed directly over game window for seamless experience
3. **Local-Only**: No cloud dependencies, no accounts, no server - just download and run
4. **Comprehensive Coverage**: From draft phase to in-game decisions
5. **Adaptive Intelligence**: Recommendations change based on real-time match state
6. **Educational Focus**: Explains WHY recommendations are made, not just WHAT to do

## Success Metrics
- User adoption and download rates
- User satisfaction with overlay experience
- Recommendation accuracy and usefulness
- Compliance with Riot Games Terms of Service
- API rate limit efficiency and optimization
- Automatic update success rate for patches/new content

## Project Constraints
- Must use only official Riot Games APIs
- No direct game client interaction or memory reading
- Must respect API rate limits
- No automation of gameplay actions
- All recommendations must be informational only
- Application must be an overlay that sits on top of the game window
- No cloud backend or server components - completely local
- No user accounts or authentication required

## Ethical Considerations
- Promote fair play and skill improvement
- Avoid creating unfair advantages through automation
- Maintain transparency about data sources
- Respect player privacy and data security
